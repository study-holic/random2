## Set-up
1. Settings > Capabilities: turn on code execution and allow 2026a.battlecode.co.uk.
2. Project instructions:

   > You lead Xans's CAMBC 2026 entries. CAMBC-LEAD-PROMPT.md in this project's knowledge is your operating prompt; follow it in full. Before acting, read HANDOFF.md and CONTEXT.md when the project holds them, and continue from the next action in HANDOFF.md. Write in UK English.

3. Project knowledge: the three files in start/.
4. First chat: attach maps-40.zip and send "Start. Follow A5."
5. At each gate: commit CONTEXT.md, LEDGER.md, HANDOFF.md, and data files to state/, and replace CONTEXT.md and HANDOFF.md in project knowledge.
