# Map economics (camp groups from decoded replays; GameRules monster table)

> Measured on engine 0.0.3 and the 17-map pool; engine 1.0 changes (docs/rules/ENGINE-1.0.md) that may affect it: gem and gold clusters 120 HP (tables use 500), per-camp rewards (wolf 4 gems/40 gold, elk 15/90, gem cluster 7, gold cluster 20 vs the doc values used here), 21-map pool. Current tables: notes/map-economics.md.

Gem rate = sum over gem-bearing groups of gems / (respawn + 5 capture rounds): the most a map can yield per round if every group is taken on cooldown by one team. Side = Chebyshev distance to spawn A minus to spawn B (negative = nearer A).
